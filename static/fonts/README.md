# Space Grotesk

`space-grotesk-variable.woff2` is the upstream variable font (weights 300–700),
downloaded on 16 September 2026 from the Space Grotesk project:
https://github.com/floriankarsten/space-grotesk/tree/master/fonts/woff2

Upstream Git blob: `0c4d65824309f9107f096fb4421e14782cb3ec81`.
The full SIL Open Font License is included in `LICENSE.txt`.
One WOFF2 file replaces four separate TTF weights and includes the upstream
character coverage without external font requests.
