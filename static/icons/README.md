# App Icons

This folder is a placeholder for PWA icons referenced in `manifest.webmanifest`.

- `icon-192.png` – 192×192 PNG
- `icon-512.png` – 512×512 PNG
- `maskable-icon-512.png` – 512×512 PNG with safe padding for maskable displays

Replace these placeholders with final artwork before releasing.

`remixicon.css` and `remixicon.woff2` are Remix Icon v4.2.0, released under
the Apache License 2.0. Source: https://github.com/Remix-Design/RemixIcon
